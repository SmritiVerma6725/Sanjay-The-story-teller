## 4. Evaluator Independence & Rights Protocol

The outreach workflow enforces the following linguistic and ethical protections:
1. **Zero Presumption of Correctness:** No invitation claims that the candidate animation is accurate, natural, or production-ready.
2. **Dedicated Unassessable Option:** Evaluators can mark any parameter as `NOT_ASSESSABLE` (specifically mandated for facial markers due to rigid Y-Bot geometry).
3. **Dedicated Uncertainty Flag:** Evaluators can flag monocular ambiguity or request multi-view reference captures.
4. **No Forced Consensus:** If two reviewers submit conflicting assessments, both records are preserved in full. Disagreement is treated as vital linguistic data.
5. **No Commercial or Coercive Incentives:** Evaluators are informed that SignBridge is open-source, and their evaluation carries no obligation to endorse the software.

---

## 5. Contact Verification & Data Minimization Rules

1. **Passive Directory Audit:** Published contact addresses must be verified against current institutional web pages at the time of review. Addresses must not be assumed valid without checking.
2. **Sensitive Personal Data Minimization:** Reviewers are never asked for government identification numbers, financial accounts, physical home addresses, or demographic data beyond voluntarily disclosed signing background (e.g., Deaf native signer, certified interpreter, or academic linguist).
3. **Follow-Up Limitation:**
   - Unsolicited follow-up is restricted to **maximum one (1) reminder**.
   - A minimum cooling-off period of **seven (7) calendar days** must elapse before sending a reminder.
   - If no reply is received following the single reminder, the status transitions to `NO_RESPONSE` and all contact ceases.
