## 3. Status Classification Definitions

- **`IMPLEMENTED`:** Code, scripts, and configurations are authored, functional, and present in the repository.
- **`TESTED_IN_REPORTED_ENVIRONMENT`:** Empirically verified with automated tests passing on the reported hardware and software stack.
- **`TECHNICALLY_READY`:** Architecture, contracts, error handlers, and integration harnesses are complete and verified.
- **`EXPERIMENTAL`:** Working feature or prototype component with known limitations, pending formal evaluation.
- **`QUARANTINED`:** Component is deliberately isolated from the default production registry to prevent accidental promotion.
- **`IMPLEMENTED_UNVALIDATED`:** Code/asset is functional and rendered in production, but has not received formal qualified human review.
- **`AWAITING_HUMAN_VALIDATION`:** Requires evaluation by certified Deaf-native signers before accuracy claims can be made.
- **`BLOCKED_BY_LICENSING`:** Deployment or redistribution is legally constrained pending authoritative copyright clarification.
- **`PENDING_OWNER_APPROVAL`:** Policy or budget deviation recorded and awaiting formal Project Owner sign-off.
- **`NOT_IMPLEMENTED`:** Identified feature or tier that is not yet authored.
